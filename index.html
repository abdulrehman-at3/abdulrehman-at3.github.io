Verified · Flask app

PhishGuard

Context‑aware phishing email detector

The first version flagged any email containing words like verify, OTP, or limited time — which meant ordinary marketing mail and routine login codes got caught alongside real phishing. v2 separates the two questions that actually matter: what kind of message is this, and is there real evidence of an attack? Marketing and routine security language only count against a message when paired with hard evidence — a spoofed sender or a malicious link — never on their own.

  • Classifies message type before scoring — Marketing, Security Notice, Transactional, Newsletter, Personal
  • Evidence‑based 0–100 risk score: spoofed senders, lookalike URLs, credential requests
  • Surfaces positive indicators, not just red flags
  • CSRF protection, rate limiting, secure headers, sanitized input — OWASP‑inspired
  • 35 automated tests across the classifier and the full request cycle

  • Bootstrap 5
  • JavaScript
  • Pytest

Password strength & entropy analyzer

Built in week one of my DecodeLabs internship to go past a simple length check. CyberShield scores a password on composition, estimates its entropy and brute‑force search space, and checks it against common‑password and dictionary‑word lists — then explains exactly why the score landed where it did.

Verified · Crypto CLI

Encrypto

Encryption / decryption toolkit

One command‑line interface over three ciphers: classical Caesar and Vigenère for the fundamentals, and password‑derived AES‑256 in authenticated GCM mode for the real thing. Every AES token carries its own salt, nonce, and authentication tag — a wrong password or a single edited character and the token is rejected outright, not silently decrypted into garbage.

  • Caesar and Vigenère ciphers for classical cryptography fundamentals
  • AES‑256‑GCM with password‑derived keys (PBKDF2 + PyCryptodome)
  • Tamper detection — modified or mismatched tokens are rejected, not decrypted
  • URL‑safe Base64 tokens bundling salt, nonce, and auth tag
  • Unit‑tested cipher and utility modules
  • Python
  • PyCryptodome
  • AES‑GCM
  • Unittest
